CodePilot — recorded sessions

A small coding agent that edits a real git repository: it reads the code, changes it, runs the tests, and checkpoints every turn so codepilot undo puts things back. These are recordings of real runs — the same event stream the terminal prints, replayed at its original pacing. Nothing is simulated, and nothing is re-enacted. The cost on each one is what it actually cost.

There is no live demo here, because a live demo would mean running shell commands for strangers on hardware I pay for. It can be hosted — there is a server mode that runs every command in a locked-down container, requires callers to bring their own key, and hands back a patch instead of writing to your branch — but the thing to do with it is clone it, add your own key, and point it at your own repository.

It was also built to measure its own design rather than assert it. Four experiments, twenty tasks, each scored by held-out tests the agent never sees. Two of them contradicted the design and the design changed: whether to rewrite a file or edit it in place reverses with file size, and the symbol index this project is named after never beat plain grep. The numbers, and the raw results files behind them, are in the repository.
